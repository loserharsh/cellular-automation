# Cellular Automata in C++

An exploration and implementation of Cellular Automata built from scratch in C++, covering 1D Wolfram Elementary Automata (e.g. Rule 30, Rule 110) and 2D Conway's Game of Life.

## Overview
A Cellular Automaton is a discrete computational model consisting of a regular grid of cells, each with a finite set of states that evolve over discrete time steps according to fixed mathematical rules based on local neighbors.

## Build and Run
```bash
g++ CA.cpp -o CA
./CA
```
